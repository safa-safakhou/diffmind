## Reproduction and limits

The [manifest](manifest.json) records binary and retained-artifact hashes. [Observer sources](harness/) preserve the executed sequences as `.txt` artifacts, not a supported test framework. Replace absolute runtime/source paths with your candidate paths, create fresh private directories/homes, copy authorized test sources, and prepare the analyzer wrapper before company trials. Generate a new proxy secret in each run; do not log or publish it. The large-render fixture entry was bundled against current product components; its driver uses an isolated browser page. The checkout driver requires a nonexistent demo destination and invokes `scripts/prepare-showcase.sh` and `scripts/apply-demo-shop-change.sh` only in that destination.

Observer corrections: a horizontal SVG path has a zero-height visibility box, so the evidence observer waits for attachment before keyboard focus; it does not simulate a product click. The rendered full-detail label selector was corrected to `.flow-service-name`. The checkout observer initially used the wrong response property and incorrectly expected all five modifications to be substantive; final observations use `change` and retain the accurate provenance distinction. These failed observer assertions were corrected before the final passed receipts.

No human participants were recruited. Company-source semantic accuracy, a large real extraction corpus, PR false-alarm/miss calibration, installed-client adoption and production identity/proxy deployment are not established by these trials. Historical snapshots are read-only; absent file scopes and analyzer versions are unknown. Recovery flags deliberately do not authorize automatic mutation retries, since a lost response does not prove the operation was not accepted.
