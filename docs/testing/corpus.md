# Automated source and PR oracle protocol

The owner requires Codex to perform all verification without human reviewers or sign-off. Expected results must still come from inputs and independent computation, rather than being copied from DiffMind output.

Pin actual public supported HTTP/RPC exposures/callers and near-match negatives. Keep declaration-only and unknown evidence separate. Use the Flask runtime URL map, independently parsed literal source contracts, contract schema comparisons and controlled metamorphic changes as applicable. These are independent mechanisms, not claims of independent human review.

1. Record source/upstream/derived revisions, approved root/subdirectory scope and relevant literals/lines.
2. Freeze expected relationships, operation/line identity, caller revision and supported/unsupported outcomes before verification. Hash the receipt.
3. Where possible, compare two mechanisms (for example runtime registration versus static declaration parsing). Retain disagreement and unknown results instead of forcing agreement.
4. Run DiffMind and compare actual facts, assembled edges, PR tiers and public interface evidence against that oracle.
5. Retain defects and repair results; never rewrite an expected result simply to make the candidate pass. Exploratory cases may discover new expectations but must be labeled and followed by a frozen verification pass.

Include direct change, removal, internal/transitive, configuration, contract and no-impact cases. Keep controlled public-source mutations separate from actual upstream PRs. Record unavailable actual upstream categories as coverage limits; a controlled case cannot become an upstream observation. Preserve user branches and edits.

Count supported positives/negatives, unknown/disputed, unsupported and unavailable separately. For labeled supported assembled edges, report TP/FP/FN and precision/recall with denominators; zero denominator is N/A. Keep declared-subset metrics separate. A clean head does not prove deleted callers, runtime traffic, score calibration or merge safety.

A new language/framework outside the detector's supported contract is a recorded coverage limit; it does not authorize inventing exact evidence. MNI-197/198/199/202 use this automated evidence standard. No human acceptance task remains.
